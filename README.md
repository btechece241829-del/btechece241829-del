### 🏆 Featured Flagship Project: SMART MINE

#### *AI-Based Smart Governance & Compliance Monitoring Platform for Coal Mines*

> **Smart Mine** is an advanced compliance and safety management system built for high-risk mining environments. It integrates real-time IoT hazard detection, predictive machine learning risk models, statutory DGMS inspection workflows, and a **hybrid blockchain trust layer** (10 Solidity smart contracts) to create an immutable, tamper-evident audit trail without sacrificing client-side responsiveness.

<tr>
<td valign="top">

- 📊 **AI-Powered Compliance Monitoring**: Automated audit engine evaluating statutory DGMS safety rules and mine regulation guidelines in real time.
- ⚡ **Predictive Risk Detection**: Flask ML microservice blending **13 operational datasets** with live telemetry using `IsolationForest` to assign dynamic risk scores and hazard bands (*Low / Moderate / High / Critical*).
- 📄 **OCR Document Digitization**: Client-side `tesseract.js` OCR scanning physical inspection certificates, gas test slips, and statutory paper records into structured JSON.
- 💬 **Complaint Management**: Event-sourced grievance tracking with anonymous hazard reporting, immutable status transitions, and automated SLA escalation.
- 🔍 **Inspection Workflows**: Digital statutory checklists, violation severity scoring, photo/video evidence capture, and automated Corrective & Preventive Action (CAPA) tracking.
- ⏱️ **Attendance Management**: QR-code badge check-ins, underground shift rosters, contractor headcount reconciliation, and real-time in-mine zone tracking.

</td>
<td valign="top">

- 🔥 **Firebase Integration**: Production state management using **Firebase Firestore** as the interactive source of truth, **Firebase Auth** for cryptographic role-based claims, and **Firebase Storage** for inspection media.
- ⛓️ **Blockchain Trust Layer**: **10 Solidity 0.8.24 ledgers** deployed with Hardhat (chainId `31337`). Anchors deterministic canonical SHA-256 hashes of all statutory records on-chain via `ethers.js v6`.
- 📜 **Tamper-Evident Audit Trail**: Independent verification engine (`VERIFIED`, `TAMPERED`, `NOT_FOUND`) ensuring mathematical auditability with zero silent mutations.
- 🗺️ **GIS & Location Support**: Interactive Leaflet / React-Leaflet spatial mapping rendering GeoJSON mine pit perimeters, shaft locations, incident pins, and live sensor telemetry.
- 🔒 **8-Tier Role-Based Access (RBAC)**: Fine-grained permission matrix enforced across Mine Workers, Safety Officers, DGMS Inspectors, and Site Admins with dual-layer rule validation.
